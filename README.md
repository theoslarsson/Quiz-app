# Quiz App

A simple quiz application built with HTML, CSS and JavaScript.

## Live Demo

## Live Demo

[Try the quiz](https://theoslarsson.github.io/Quiz-app/)

## Features

- Multiple-choice questions
- Score tracking
- Correct and wrong answer feedback
- Final score screen
- Restart functionality
- Questions created using a JavaScript class
- Dynamic question and answer updates
